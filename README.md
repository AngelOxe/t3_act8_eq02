# MediCita — Actividad 8 — Equipo 02

**Estado:** base técnica inicial (antes de los módulos 1 y 2).

## Instalación

Requiere Node.js 20.19+ o 22.12+ y npm.

```bash
npm install
npm run dev
```

Abrir la URL que muestra Vite. En esta fase aparece la pantalla de base.

## Trabajo del equipo

- Integrante 1: Login, autenticación, dashboard, sidebar y navbar.
- Integrante 2: Tabla DummyJSON, filtros, paginación y CRUD.
- Rama principal `main`: solo integraciones revisadas.
- Ramas del integrante 1: `feature/login` y `feature/dashboard`.
- Ramas del integrante 2: `feature/tabla` y `feature/crud`.
